# CircuitLab

Статический прототип мастерской для DIY-проектов с микроконтроллерами. Интерфейс работает без сервера и готов к публикации через GitHub Pages.

## Публикация на GitHub Pages

1. Создайте пустой репозиторий на GitHub.
2. Отправьте в него файлы этой папки в ветку `main`.
3. В настройках репозитория откройте **Settings → Pages** и выберите источник **GitHub Actions**.
4. После отправки коммита workflow `.github/workflows/pages.yml` автоматически опубликует сайт.

## Возможности прототипа

- Адаптивный интерфейс мастерской и создание собственных проектов с названием, описанием и платой.
- Каталог из 21 компонента: платы Arduino/ESP32/Pico, датчики, дисплеи, моторы, реле, питание и детали макетирования.
- Добавление и удаление деталей на поле собственной схемы.
- Редактирование и копирование Arduino-скетча, масштабирование поля и визуальная демонстрация мигания светодиода.
- Автосохранение проектов, деталей и кода в локальном браузере.

Симуляция здесь визуальная: электрический расчёт схемы и прошивка микроконтроллера пока не подключены. Проекты хранятся локально в браузере пользователя.
