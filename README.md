# CircuitLab

Статический прототип мастерской для DIY-проектов с микроконтроллерами. Интерфейс работает без сервера и готов к публикации через GitHub Pages.

## Публикация на GitHub Pages

1. Создайте пустой репозиторий на GitHub.
2. Отправьте в него файлы этой папки в ветку `main`.
3. В настройках репозитория откройте **Settings → Pages** и выберите источник **GitHub Actions**.
4. После отправки коммита workflow `.github/workflows/pages.yml` автоматически опубликует сайт.

## Возможности прототипа

- Адаптивный интерфейс мастерской и создание собственных проектов с названием и описанием; добавление платы необязательно.
- Каталог из 40 компонентов с поиском и фильтрами: платы, датчики, измерительные приборы и генераторы сигналов, дисплеи, моторы, модуль зарядки TP4056 и обычные электронные детали.
- Добавление и удаление деталей на поле собственной схемы.
- Перетаскивание модулей по полю, собственные изображения плат с контактными площадками и сохранение их позиции.
- Редактирование и копирование Arduino-скетча, масштабирование поля и визуальная демонстрация мигания светодиода.
- Автосохранение проектов, деталей и кода в локальном браузере.

Симуляция здесь визуальная: электрический расчёт схемы и прошивка микроконтроллера пока не подключены. У генератора импульсов 400 кВ есть условные клеммы, чтобы рисовать провода на макете; это не схема реального устройства и не инструкция по созданию. Проекты хранятся локально в браузере пользователя.
